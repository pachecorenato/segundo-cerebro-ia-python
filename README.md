# 🧠 Segundo Cérebro com IA: Inteligência Artificial com Python

Projeto desenvolvido como parte do Desafio de Projeto da [DIO](https://dio.me), utilizando o **Gemini Notebook** (antigo NotebookLM) para criar um especialista pessoal de estudos alimentado por fontes curadas.

---

## 🎯 Tema e Objetivo
> **Objetivo:** "Criar um guia prático para entender os conceitos básicos de Inteligência Artificial e dar os primeiros passos em Python, aprendendo a usar as principais bibliotecas para construir modelos de Machine Learning."

## 📚 Fontes Selecionadas e Critérios de Confiança

As fontes foram selecionadas em múltiplos formatos para garantir diversidade e profundidade:

1. **Vídeos no YouTube (Playlist de IA com Python):**
   - *Por que confiar:* Vídeos didáticos em sequência lógica cobrindo desde a introdução teórica até a implementação de algoritmos passo a passo.
2. **Artigo Rocketseat (Desenvolvendo Agentes de IA com Python):**
   - *Por que confiar:* Portal de referência na comunidade de desenvolvedores no Brasil, com foco em boas práticas e tecnologias atuais.
3. **Guia em Documento (Scribd - Python AI Guide):**
   - *Por que confiar:* Material técnico e estruturado que serviu como referência teórica para a arquitetura de conceitos e modelos.

---

## 🤖 Diretriz de Comportamento (Prompt)
Para garantir que a IA respondesse como um mentor focado apenas no material de estudo, foi configurada a seguinte diretriz:

> *"A partir de agora, comporte-se como um mentor especialista em Inteligência Artificial e Python. Seu objetivo é me ajudar a entender os conceitos básicos de Machine Learning e o uso das principais bibliotecas. Use uma linguagem clara, didática e adequada para iniciantes. Baseie suas respostas EXCLUSIVAMENTE nas fontes fornecidas. Sempre que explicar um conceito, tente dar exemplos simples práticos."*
